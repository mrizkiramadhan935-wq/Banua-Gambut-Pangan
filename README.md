# Banua Gambut Pangan — Master Tailwind

Website final berdasarkan seluruh revisi desain dan konten Banua Gambut Pangan.

## Teknologi
- HTML5
- Tailwind CSS via CDN
- JavaScript vanilla untuk filter produk, menu mobile, dan fitur Cari Beras
- Google Fonts: Montserrat (dipilih karena paling mendekati karakter tipografi logo Banua Gambut Pangan)

## Struktur
- index.html — Beranda
- tentang.html — Tentang Kami
- produk.html — Katalog 10 produk + filter tekstur
- cari-beras.html — Rekomendasi berdasarkan menu
- produk/*.html — 10 halaman detail produk terpisah
- assets/ — logo, background sawah, dan foto produk

## Arah visual
- Fun, modern, clean, warm
- Palet hijau, emas, cream, dan putih sesuai logo BGP
- Hero memakai background sawah tanpa border/frame
- Tidak menggunakan ikon dekoratif atau emoji
- 4 kolom produk di desktop, 2 di tablet, 1 di mobile
- CTA pembelian menggunakan teks “Belanja Sekarang”

Buka index.html menggunakan Live Server di Antigravity IDE atau VS Code.
